2. The bug is that sum is passed into read_values by value, so
   read_values only changes a copy of sum. The original sum variable
   in main is still 0 after read_values finishes.

3. I fixed it by changing the parameter to a double pointer:

   int read_values(double *sum)

   Then I pass the address of sum from main:

   values = read_values(&sum);

   Inside read_values, I use *sum to access and change the original
   sum variable.
